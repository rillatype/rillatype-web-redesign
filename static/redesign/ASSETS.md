# Aset preview editorial

- `manrope.ttf` berasal dari https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf.
- Lisensi font asli disimpan sebagai `OFL-Manrope.txt`, dari https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt.
- Font UI dimuat lokal. Tidak ada stylesheet font pihak ketiga pada runtime.
- Logo memakai `../../logo.png`, aset yang sudah tersedia di repo.
- Gambar font memakai `../previews/`, aset yang sudah tersedia di repo. Tidak ada gambar AI atau gambar stock baru.
- Font produk Mango pada detail memakai `../previews/mango-letter.otf`. Hak distribusi final file specimen perlu diperiksa sebelum production.
- `fonts/chronoa-*.otf` berasal dari folder kerja pengguna `Font Test` dan hanya dipakai sebagai specimen tester, bukan font UI. Sembilan bobot: Thin 100, ExtraLight 200, Light 300, Regular 400, Medium 500, SemiBold 600, Bold 700, ExtraBold 800, Black 900. Hak distribusi final perlu diperiksa sebelum production.
- `../previews/chronoa-1.jpg` dirender dari berkas Chronoa asli dengan Pillow, bukan artwork hasil generasi. Cover ini dipakai pada kartu koleksi homepage.
