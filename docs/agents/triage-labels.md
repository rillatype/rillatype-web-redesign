# Label triage

Gunakan pemetaan berikut untuk lima peran triage canonical.

| Peran skill | Label tracker | Makna |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer perlu mengevaluasi issue. |
| `needs-info` | `needs-info` | Menunggu informasi tambahan dari pelapor. |
| `ready-for-agent` | `ready-for-agent` | Spesifikasi lengkap dan siap dikerjakan agent. |
| `ready-for-human` | `ready-for-human` | Memerlukan pengerjaan manusia. |
| `wontfix` | `wontfix` | Tidak akan ditindaklanjuti. |

Saat skill menyebut suatu peran, gunakan label tracker pada tabel.
Ubah kolom label tracker jika kosakata repo berubah.
