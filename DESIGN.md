# Design System: Rillatype

## Overview

**Creative North Star: "Foundry editorial"**

Pemilik menolak homepage R05D/R05E/R05F. Tiga keberatan yang dicatat: headline hero bertabrakan dengan lettering di dalam artwork, display type tanpa karakter, dan kartu masih terasa template. R05G mengganti homepage itu dengan arah **Specimen Hall**: huruf produk menjadi isi utama, bukan latar bagi headline.

Komposisi R05G berurutan: header terang sticky (logo, navigasi, search) → hero grid `1.55fr:1fr` dengan artwork Chronoa asli di kiri dan pelat informasi di kanan (nama produk, tabel spec empat baris, aksi utama) → specimen hidup yang dapat diketik → tiga strip specimen (300 Light, 500 Medium, 600 SemiBold) → The collection, indeks sepuluh baris satu typeface per baris → Beyond type, rak artwork dan tiga tautan kategori → galeri "Mango Letters in use" berisi tiga gambar aplikasi asli → blok lisensi → catatan preview → footer. Tidak ada card di dalam homepage: garis rambut dan whitespace yang memisahkan konten. R06 dan R06A tetap berlaku pada halaman produk.

Dokumen ini merekam `static/redesign/index.html`, `product.html`, `catalog.html` (halaman yang memakai aturan `.browse`/`.filter` bersama), `style.css`, `editorial.css`, `preview.js`, `product-preview.js`, `font-catalog.js`, dan `tester-core.js`. Halaman redesign memuat base stylesheet sebelum override editorial. Sistem component lab berbasis system sans tetap terpisah. Dokumentasi merekam implementasi, bukan persetujuan user, hasil review, verdict ship, atau hasil pengukuran performa.

**Key Characteristics:**
- Manrope untuk UI, metadata, harga, dan navigasi; Rilla-Chronoa dan Rilla-Mango hanya untuk specimen produk.
- Biru `accent` untuk fokus dan hover; tindakan utama memakai tinta `rule`, bukan biru.
- Artwork produk asli mempertahankan warna dan radius gambar 0; bingkai hero, rak, dan galeri bersudut siku.
- Berkas specimen dimuat hanya saat dibutuhkan, dan font UI tidak pernah dipakai sebagai pengganti specimen.
- Halaman produk memakai OTF penuh lewat `tester-core.js`; homepage memakai subset WOFF2 di `fonts/web/`.
- Pencarian header sticky tetap terlihat saat menu mobile tertutup.
- Gallery dan lisensi memakai tombol serta radio native.

## Colors

### Primary
- **Accent blue** (`accent` `#2247c8`) memberi warna pada outline fokus keyboard, caret specimen, hover `text-link`, `section-link`, dan nama baris indeks. Tombol utama tidak memakai warna ini.
- **Rule ink** (`rule` `#12151c`) adalah tinta tindakan: background serta border tombol utama, keadaan terpilih pada cut/weight picker, segmented tester, sakelar, filter aktif, thumbnail aktif, dan radio lisensi; juga `::selection`, border atas specimen band, dan border bawah heading koleksi.

### Neutral
- **Paper** (`paper`) adalah halaman, header, bidang specimen, rak, dan tombol sekunder.
- **Ink** (`ink`) adalah teks utama, border tombol sekunder, dan isi `row-name`, `spec-value`, dan `strip-cap b`.
- **Muted** (`muted`) membedakan copy hero, `spec-label`, `row-meta`, `strip-cap`, catatan preview, dan empty state.
- **Line** (`line` `#d9d9d4`) memisahkan header, baris indeks, rak, galeri, blok lisensi, tester, dan catatan preview. Nilai ini menimpa base `base-line` `#d9d9d9` pada halaman editorial.
- **Wash** (`wash` `#f4f4f2`) adalah field pencarian, latar artwork, thumbnail baris, panel opsi tester, textarea, select, dan opsi lisensi terpilih. Nilai ini menimpa base `base-wash` `#f4f4f4`.
- **Transparent** (`transparent`) dipakai pada border field pencarian dan filter default.
- Token `base-line`, `base-wash`, dan `base-ink-hover` mencatat base component lab saja. Override editorial tidak memakai palette base tersebut.

`.editorial` masih mendeklarasikan `--accent-hover: #1a379b`, tetapi tidak ada aturan yang mereferensikannya. Hover tombol utama memakai literal `#2c2f36`; hover tombol sekunder memakai Wash.

Tonal ramp di sidecar adalah metadata panel sintetis. Ramp tidak menambah warna runtime.

**The One Accent Rule.** Gunakan biru sebagai satu aksen UI; pertahankan warna asli artwork, dan pakai Rule ink untuk tindakan utama alih-alih biru.

## Typography

Manrope adalah font UI, metadata, dan harga. Role editorial tanpa `fontFamily` mewarisi `body`. Font variable normal mendukung weight 200..800, termasuk 650 dan 700 yang dipakai dokumen ini. `index.html` dan `product.html` melakukan preload `manrope.ttf` dengan `crossorigin`; `@font-face` memakai `font-display: swap` dan fallback sans-serif.

File lokal `static/redesign/manrope.ttf` berasal dari repo resmi Google Fonts, `https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf`. Lisensi asli tersimpan di `static/redesign/OFL-Manrope.txt`, dari `https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt`. Runtime tidak memuat stylesheet font pihak ketiga.

### Product specimen families

R05G menambahkan dua family runtime yang membawa specimen produk asli.

- **Rilla-Chronoa** — sembilan `@font-face` dari `static/redesign/fonts/web/chronoa-*.woff2`, weight 100..900, `font-display: block`. Dipakai hero, heading section, specimen line, strip, nama baris Chronoa, blok lisensi, dan wordmark footer lewat variabel `--specimen`.
- **Rilla-Mango** — satu `@font-face` dari `static/redesign/fonts/web/mango-letters.woff2`, weight 400 saja, `font-display: block`. Dipakai nama baris "Mango Letters" dan specimen Mango.

Subset dibangun oleh `scripts/build-font-subsets.py` dari `fonts/Chronoa-*.otf` dan `static/previews/mango-letter.otf`, dengan `--unicodes` basic latin, latin-1 supplement, tanda hubung dan tanda kutip melengkung, serta beberapa simbol; `--layout-features=*`, `--flavor=woff2`, `--no-hinting`, dan `--desubroutinize`. Sembilan OTF Chronoa berukuran 204,4 KB dan `mango-letter.otf` 60,3 KB (total 264,7 KB); hasilnya 94,4 KB untuk Chronoa dan 31,7 KB untuk Mango, total 126,1 KB WOFF2. Berkas OTF penuh tetap dipakai tester halaman produk; homepage hanya memakai subset.

Angka dibaca langsung dari berkas yang dikirim (tabel `maxp`, `cmap` format 4, dan `GSUB`): setiap berkas Chronoa memuat 219 glyph dan 218 codepoint terpetakan, dan tidak memiliki feature GSUB sama sekali. `mango-letter.otf` memuat 184 glyph, 181 codepoint terpetakan, dan feature `dlig`. `preview.js` menyimpan angka yang sama di `SPECIMENS`; baris fakta specimen menampilkan jumlah glyph dan feature, sedangkan jumlah codepoint belum ditampilkan di UI.

### Hierarchy
- `display` dan `display-mobile` mencatat H1 homepage, nama typeface unggulan di pelat hero, dirender dengan Rilla-Chronoa. Mobile berlaku pada max-width 640px; tidak ada role tablet terpisah.
- `headline` mencatat H2 section ("The collection", "Beyond type", "Mango Letters in use"). `specimen-heading` mencatat H2 specimen band yang sedikit lebih kecil; keduanya memakai Rilla-Chronoa.
- `specimen-line` mencatat baris yang dapat diketik; mobile memakai `specimen-line-mobile`. `strip-sample` mencatat tiga strip di bawahnya, yang hanya berbeda weight: 300, 500, dan 600. Caption strip berbunyi "219 glyphs · latin", "tabular figures", dan "the cut used above"; 219 adalah jumlah glyph sebenarnya, sedangkan "latin" adalah label ringkas untuk cakupan subset, bukan daftar Unicode penuh. Strip tidak lagi memuat metadata jumlah glyph yang dikarang.
- `index-name` mencatat nama baris dalam Manrope 22..30px weight 700. Baris Chronoa dan Mango Letters memakai `index-name-specimen` dan `index-name-mango` pada ukuran 28..46px, dan pada max-width 1000px turun ke 26px.
- `shelf-heading`, `license-headline`, dan `footer-wordmark` memakai Rilla-Chronoa. Wordmark footer tidak lagi Manrope.
- `product-display` mencatat H1 detail produk: clamp 34..50px, weight 600 warisan H1, line-height 1.15. Tidak ada role mobile terpisah.
- `brand` 17px/700 turun ke 16px pada max-width 640px. `navigation` 13px/600, `button` 13px/650, dan `button-hero` 14px/650 untuk tombol di pelat hero.
- `search` adalah 16px/400 karena input mewarisi font body; `filter` 13px/400; `label` 14px/400 untuk label `.search` base.
- `text-link` 14px/650 bergaris bawah offset 5px. `small` 13px/400. `spec-label` 12px/700 huruf besar dengan letter-spacing .1em; `spec-value` 13px/650 tabular.
- `row-price` 15px/650 tabular dan nowrap; `row-action` 11px/700 huruf besar letter-spacing .1em; `strip-cap` 12px/400; `picker` 12px/650; `segmented` 13px/650.

### Motion and evidence

CSS hanya mengaktifkan feedback pada `prefers-reduced-motion: no-preference`. Tombol, label aksi baris, thumbnail baris, dan nama baris memakai 160ms dengan easing `cubic-bezier(.2, .8, .2, 1)`. Thumbnail baris serta gambar galeri mendapat `will-change: transform`. Pada `prefers-reduced-motion: reduce`, hover galeri tidak mentransformasi gambar. Tidak ada siklus sample homepage, animasi intro tertunda, atau library animasi tambahan.

Agent utama menjalankan `scripts/check-specimen-home.py` terhadap server lokal dan memperoleh **30/30 PASS**. Cakupannya: heading hero adalah typeface unggulan, artwork asli tampil, specimen memuat berkas font asli dengan family Rilla-Chronoa dan weight awal 600, fakta 219 glyph, pengetikan menggerakkan specimen, pergantian weight memuat cut Light, teks pengunjung tidak ditimpa, Mango menyembunyikan picker dan melaporkan `dlig`, kembali ke Chronoa default, strip memakai face asli, baris Mango memakai Rilla-Mango dan berkasnya benar-benar termuat, pencarian "script" menyisakan Moyshire dan Radiant Summertime, pengosongan query memulihkan sepuluh baris, baris dapat dijangkau keyboard, tidak ada gambar rusak, tidak ada overflow horizontal, tidak ada error console/page/request, hero tetap tampil pada reduced motion, menu mobile terbuka dan tertutup dengan Escape, search header tetap terlihat, specimen siap di mobile, dan mobile tanpa error. Skrip juga menulis `desktop.png` dan `mobile.png` ke `.impeccable/review`.

`scripts/check-redesign-preview.py` adalah suite lama: ia masih meng-assert homepage R05D/R05E/R05F ("Type, with perspective.", 20 `.product:visible`, `.lead-information`, `.collection .product-info`), sehingga tidak lagi memverifikasi `index.html`. Tugas dokumentasi ini tidak menjalankan kedua suite; tugas ini membaca source, membaca tabel font, dan menjalankan tiga probe browser read-only: perilaku pencarian/filter `catalog.html`, tujuan tautan non-font homepage, serta tumpukan z-index skip link terhadap header sticky.

Pemeriksaan tugas dokumentasi dibatasi pada pembacaan source, pembacaan tabel font, dan paritas dengan dokumen. Harga, kategori, nama lisensi, dan pilihan unggulan tetap contoh; harga sale di `catalog.html` juga contoh. `catalog.html` belum terhubung ke data nyata, dan `scripts/check-specimen-home.py` tidak mengunjunginya, sehingga perilaku katalog di luar cakupan PASS tersebut. Dokumen ini tidak menetapkan persetujuan user, hasil review, verdict ship, performa, atau kesiapan transaksi; belum ada persetujuan visual yang tercatat untuk homepage R05G.

## Do's and Don'ts

### Do:
- Do gunakan Manrope lokal untuk UI dan metadata, dengan biru sebagai satu aksen dan Rule ink untuk tindakan utama.
- Do pakai Rilla-Chronoa dan Rilla-Mango hanya untuk specimen produk, dan ambil berkasnya saat dibutuhkan.
- Do pertahankan logo serta warna asli artwork produk dan radius gambar 0.
- Do gunakan radius kontrol 4px, pemisahan garis rambut, dan pisahkan token component lab dari override editorial.
- Do pertahankan search homepage di header sticky, di luar menu mobile, dengan label aksesibel.
- Do pertahankan `#result-count` di luar section koleksi yang dapat disembunyikan dan offset `scroll-margin-top` pada tester.
- Do gunakan tombol gallery, radio lisensi, radio picker, fokus keyboard, dan reduced motion native.
- Do tampilkan font produk hanya setelah specimen berhasil dimuat, dan laporkan jumlah glyph serta feature dari berkas asli.
- Do pertahankan label Demo dan atribusikan 30/30 PASS kepada agent utama yang menjalankan `scripts/check-specimen-home.py`.

### Don't:
- Don't kembalikan headline di atas artwork, grid kartu berulang, atau card berbingkai di homepage.
- Don't pakai metadata hasil karangan pada strip atau fakta specimen; angka glyph dan feature harus berasal dari berkas.
- Don't tampilkan fallback Manrope sebagai font produk ketika specimen gagal dimuat.
- Don't bentuk route atau path aset dari slug di luar `Map` produk, dan jangan tautkan slug non-font ke halaman detail font.
- Don't sebut Preview selection sebagai add-to-cart, pesanan, atau pembayaran.
- Don't ubah artwork menjadi palette UI atau pakai Rule ink untuk hover nama baris yang memakai biru.
- Don't samakan CSS tester mobile 44px dengan ukuran runtime awal setelah slider menetapkan 64px.
- Don't klaim pencarian katalog berfungsi selama selektor `preview.js` masih hanya mengenal `.row[data-name]`.
- Don't biarkan skip link berbagi z-index dengan header sticky sehingga tertutup saat difokus.
- Don't tambahkan raster generatif, foto baru, atau klaim hak aset dari lisensi Manrope.
- Don't artikan dokumentasi atau PASS perilaku sebagai persetujuan user, hasil review, verdict ship, atau bukti performa.
